# Mini Hospital Emergency Management System

A Java-based console application developed for the Data Structures and Algorithms assignment (CIT300).

## Implemented Data Structures
1. **Binary Search Tree (BST)** - Used for managing Patient Records using Patient ID as the key
2. **Queue** - Used for managing the Emergency Patient Waiting Unit following the FIFO principle
3. **Stack** - Used for storing completed treatment records following the LIFO principle
4. **Singly Linked List** - Used for storing individual patient visit histories

## How to Run
1. Open the project in any Java IDE (VS Code, IntelliJ IDEA, etc.).
2. Compile and run `Main.java` located inside the `src` folder.
